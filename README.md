# PADEL — всё о паделе

Статический сайт про падел: история и рост популярности, правила,
основные удары со схемами, обучающие видео и подборка матчей.

Дизайн повторяет стилистику [dvorzhik.ru](https://www.dvorzhik.ru/):
шрифт Inter, светлая тема, акцент `#ca8a04`, карточки `#f8fafc`
с рамкой `#e2e8f0`, подвал в три колонки с анимированной кнопкой
поддержки.

## Структура

```
Padel/
├── index.html          — главная: hero, разделы, «с чего начать»
├── history.html        — история игры и причины роста
├── rules.html          — правила, схема корта, счёт, ошибки
├── strokes.html        — 10 ударов с описаниями и схемами
├── tutorials.html      — обучающие видео (7 роликов)
├── matches.html        — видео с примерами профессиональной игры
└── assets/
    ├── css/style.css   — все стили
    ├── js/main.js      — кнопка поддержки + ленивые YouTube-плееры
    └── img/            — логотип, обложки, схемы ударов, схема корта
```

Сборщик не нужен: это чистый HTML/CSS/JS. Все пути относительные,
поэтому сайт работает и локально, и на GitHub Pages в подпапке
репозитория.

## Локальный просмотр

Самый простой способ — открыть `index.html` в браузере:

```powershell
Start-Process "C:\VibeCoding\Padel\index.html"
```

Если установлен Python, можно поднять локальный сервер (нужен для
проверки путей ближе к продакшену):

```powershell
cd C:\VibeCoding\Padel
python -m http.server 8000
```

Затем открыть <http://localhost:8000>.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub (например, `padel`).
2. Загрузите туда содержимое папки `Padel` (все HTML-файлы и папку
   `assets`) в корень репозитория, ветка `main`.
3. В репозитории откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**,
   ветку `main` и папку `/ (root)`. Нажмите **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу
   `https://<username>.github.io/padel/`.

Если сайт должен открываться по адресу `https://<username>.github.io/`,
назовите репозиторий `<username>.github.io`.

> Важно: главная страница должна называться `index.html` — она уже
> названа так. Файл `CNAME` нужен только для своего домена.

## Как менять контент

- **Тексты** — прямо в соответствующих HTML-файлах, разметка разбита
  на смысловые секции с комментариями в CSS.
- **Схемы ударов** — отдельные SVG в `assets/img/shot-*.svg`. Их можно
  заменить на фотографии, сохранив имена файлов или обновив `src`.
- **Видео** — карточки используют `data-video="YOUTUBE_ID"`.
  Замените ID и обложку `https://i.ytimg.com/vi/<ID>/mqdefault.jpg`.
  Плеер создаётся только по клику (см. `assets/js/main.js`), поэтому
  страница не тормозит при загрузке.
- **Подвал** — одинаковый на всех страницах; при изменении ссылок
  или кнопки поддержки правьте все шесть HTML-файлов.
- **Цвета и шрифты** — переменные в начале `assets/css/style.css`.

## Проверка перед публикацией

- Откройте каждую страницу локально и пройдитесь по меню.
- Проверьте, что схемы ударов и обложки отображаются.
- Нажмите на 1–2 видео: должен загрузиться YouTube-плеер.
- Проверьте мобильную версию (ширина окна 375–480 px): меню
  прокручивается горизонтально, подвал складывается в одну колонку.
